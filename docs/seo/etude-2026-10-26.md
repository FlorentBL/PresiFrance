## Problèmes techniques bloquants (relevés en production le 26/10/2026)

- **Fiches commune** : le HTML servi déclare `canonical = https://presifrance.fr/` et le titre de l'accueil ; aucune URL `/commune/` dans le sitemap (174 URL : 102 départements, 47 pages 2027, pages nationales). Les ~35 000 fiches ne peuvent pas être indexées.
- **HTML servi vide** : sur les pages prérendues (ex. fiche Glucksmann, /explorer/69), le corps contient 1 mot visible et aucun H1 ; seules les balises meta sont prérendues. Google doit exécuter le JavaScript, les IA ne voient rien.
- `www.presifrance.fr` redirige bien en 301 vers `presifrance.fr` (OK).
